# Carisite

Static-first landing page for **Carisite** — a web-development service for
Indonesian SMEs (UMKM). Built as a JAMstack site with Astro: every page is
pre-rendered at build time and can be served from any static host/CDN. No
backend, no database — leads are captured via WhatsApp deep links.

The UI is sliced from the design system in [`docs/design`](docs/design)
(the "Growth Narrative" emerald-green palette, Plus Jakarta Sans, Bahasa
Indonesia copy).

---

## Tech stack

| Layer              | Technology                                  |
| ------------------ | ------------------------------------------- |
| Framework          | [Astro 5](https://astro.build) (SSG)        |
| Styling            | Tailwind CSS v3 (`@astrojs/tailwind`)       |
| Content            | Astro Content Collections (MDX + JSON)      |
| Interactive bits   | Vanilla JS islands (no UI framework)        |
| Icons              | `astro-icon` + `@iconify-json/lucide`       |
| Fonts              | `@fontsource/inter` + `plus-jakarta-sans`   |
| SEO                | `@astrojs/sitemap`, JSON-LD, OG/Twitter meta|

## Prerequisites

- **Node.js 18.20+ or 20+** (developed on Node 20)
- npm (ships with Node)

## Getting started

```bash
# 1. Install dependencies
npm install

# 2. Start the dev server (http://localhost:4321)
npm run dev
```

## Available scripts

| Command           | Description                                          |
| ----------------- | ---------------------------------------------------- |
| `npm run dev`     | Start the local dev server with HMR at `:4321`       |
| `npm run build`   | Type-check + build the static site into `dist/`      |
| `npm run preview` | Serve the production build locally at `:4321`        |
| `npm run check`   | Run `astro check` (type & diagnostics, 0 errors)     |

Production build output lands in `dist/` and is ready to deploy to any static
host (Netlify, Vercel, Cloudflare Pages, GitHub Pages, etc.).

## Configuration

All site-wide settings live in [`src/config/`](src/config):

- **`site.ts`** — brand name, **WhatsApp number**, contact email, domain, URL.
  > ⚠️ Set the real `whatsapp` number (format `628xxxxxxxxxx`) before going
  > live — it currently holds a `628xxxxxxxxxx` placeholder. It powers the
  > floating button, the order form, and every "Konsultasi" CTA.
- **`navigation.ts`** — the navbar / anchor links.

Design tokens (colors, fonts, radius, shadows) are defined in
[`tailwind.config.mjs`](tailwind.config.mjs). The site URL used for canonical
tags and the sitemap is set in [`astro.config.mjs`](astro.config.mjs).

## Content authoring

The site is data-driven via Content Collections (schema in
[`src/content/config.ts`](src/content/config.ts)):

**Add an article** — create `src/content/articles/my-post.mdx`:

```mdx
---
title: "Judul Artikel"
description: "Ringkasan singkat untuk SEO & kartu artikel."
category: "Tips"
publishDate: 2026-06-01
image: "/images/articles/my-post.svg"
---

Isi artikel dalam Markdown / MDX...
```

**Add a demo website** — create `src/content/demo/my-demo.json`:

```json
{
  "title": "Website Contoh",
  "description": "Deskripsi singkat.",
  "category": "Kategori",
  "image": "/images/demo/my-demo.svg",
  "demoUrl": "https://example.com",
  "features": ["Fitur 1", "Fitur 2"]
}
```

Both are picked up automatically — articles appear on `/articles` (the home
page shows the latest 4), and demos appear in the Demo section. Place the
referenced images under `public/images/`.

## How it works (summary)

- **Static rendering.** All routes are generated at build time via
  `getStaticPaths()`; there is no server runtime.
- **Lead capture without a backend.** The order form and every CTA build a
  pre-filled `wa.me` deep link (the WhatsApp number is read from a `data-wa`
  attribute injected from `site.ts`, never hardcoded in scripts).
- **Interactivity is vanilla JS.** Small `<script>` islands handle the mobile
  drawer, scroll-spy active link, stats count-up, reveal-on-scroll animations,
  the FAQ accordion (`<details>` + `aria-expanded`), and order-form validation.
  No React/Vue/Svelte.
- **Accessibility & motion.** Animations respect `prefers-reduced-motion`;
  interactive controls have `aria-*` labels and are keyboard-navigable.
